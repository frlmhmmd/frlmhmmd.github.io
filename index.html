Kenapa Teknologi? Cerita di Balik Passion

Bagi saya, teknik informatika bukan sekadar baris kode di layar monitor — melainkan jembatan nyata yang menghubungkan logika digital dengan kebutuhan manusia dan perangkat fisik di dunia nyata.

Mengapa Suka Web Development?

Web adalah media tercepat untuk menyampaikan ide ke seluruh dunia. Saya menyukai kepuasan saat merancang antarmuka yang intuitif, responsif, dan menghubungkannya dengan logika backend serta API yang kokoh untuk memecahkan masalah pengguna.

Mengapa Tertarik Physical Networking & IoT?

Ada kepuasan tersendiri saat melihat kabel LAN terhubung rapi, konfigurasi routing bekerja mulus, hingga mikrokontroler sensor IoT membaca kecepatan kendaraan di jalan raya dan mengirimkan datanya secara real-time melalui jaringan nirkabel.

Mengapa Menekuni Cyber Security & Data?

Sistem yang canggih tidak ada gunanya jika rentan dibobol. Ketertarikan saya pada keamanan aplikasi menginspirasi saya membuat tool keamanan seperti SecretLee (terinspirasi dari konsep Burp Suite). Sementara dengan data & SQL, kita bisa mengambil keputusan berbasis bukti, bukan tebakan.
